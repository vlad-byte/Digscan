# DigitScan

Android-приложение (Kotlin, Jetpack Compose), которое работает полностью офлайн.

## Сценарий
1. **История** — список сессий. «Новая сессия» создаёт сессию; незавершённая сессия продолжается по тапу,
   завершённая открывается как результат.
2. **Шаг 1 — съёмка.** Камера (CameraX), кнопка спуска, лента миниатюр (крестик удаляет снимок), подсветка.
3. **Шаг 2 — проверка текста.** Для каждого фото текст распознаётся на устройстве (ML Kit), его можно
   поправить вручную (1–20 символов). Кнопка «Завершить сессию» активна, когда все строки корректны.
4. **Завершение:** каждый «/» заменяется на «00», строки сортируются по возрастанию и сохраняются как итог
   сессии. Сессия получает статус «Завершена».
5. **Просмотр сессии:** итоговый список (копировать / поделиться), фотографии сессии с распознанным текстом,
   удаление сессии вместе с файлами.

## Стек и структура
- UI: Jetpack Compose + Material 3, Navigation Compose
- Камера: CameraX 1.3.4
- OCR: ML Kit Text Recognition (Latin, модель в составе APK — интернет не нужен)
- Хранение: Room (sessions / photos / result_lines), фото — в `filesDir/sessions/<id>/`

```
domain/TextProcessing.kt   замена «/» → «00», сортировка, валидация
data/                      Room, Repository, OcrEngine
ui/                        AppNav, ViewModels
ui/screens/                History, Capture, Review, SessionDetail
```

## Сборка
Android Studio Ladybug (2024.2) или новее, JDK 17. Откройте папку проекта, дождитесь Gradle Sync, запустите
`app` на устройстве или эмуляторе с камерой. Если Studio не подтянет Gradle Wrapper, выполните `gradle wrapper`.
Package/applicationId по умолчанию `com.example.digitscan` — замените на свой.

## Допущения по ТЗ (меняются в `TextProcessing`)
- «Заменяется на 00» понято как замена каждого символа «/» на «00» (`12/34` → `120034`).
- Текст хранится и сортируется как строка (посимвольно): `10` идёт раньше `2`; цифры раньше букв.
- Пробелы и переносы строк из текста удаляются.
- Если на фото несколько блоков текста, берётся самый крупный.

## Сборка APK без Android Studio
Репозиторий содержит `.github/workflows/build.yml`: загрузите проект на GitHub, во вкладке Actions
запустится сборка, готовый `app-debug.apk` лежит в Artifacts.
